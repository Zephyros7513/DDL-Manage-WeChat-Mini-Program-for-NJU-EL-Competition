# 大学生智能 DDL 管理小程序

这是一个可导入微信开发者工具的小程序前端原型，覆盖“随手录入、智能分级、长期任务拆解、提醒规划、日历拥挤度、数据看板、团队协作模板”等核心功能。

## 如何运行

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件夹。
4. AppID 可继续使用测试号或填自己的小程序 AppID。
5. 编译运行。

## 已实现功能

- 任务页：自然语言快速录入，自动识别任务类型、截止日期、截止时间和提醒节奏。
- 智能分级：按剩余天数与重要程度生成“立刻处理 / 本周重点 / 稳定推进 / 低压安排”。
- 长期任务拆解：论文、竞赛、考试、普通作业会生成不同阶段计划。
- 日历页：展示当月 DDL 拥挤度，并可查看某天任务。
- 看板页：统计完成率、待办数、高压任务、任务类型分布，并给出本周建议。
- 协作页：共享任务看板、复制邀请语、校园任务模板。

## 后续可接入

- 云开发数据库：替换当前本地 `wx.setStorageSync`。
- 订阅消息：接入微信小程序订阅消息做真实提醒。
- 课表导入：对接学校教务系统、Excel/图片识别或手动课表模板。
