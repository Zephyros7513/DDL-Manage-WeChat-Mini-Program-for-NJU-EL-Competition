# 南雍清序：面对南京大学学生的智能任务规划与协作管理小程序运行手册

## 1. 项目简介

这是一个基于微信小程序原生框架开发的 DDL 管理原型。项目面向大学生日常学习任务管理，支持任务录入、智能分级、阶段拆解、课表维护、日历负载查看、统计分析和团队协作。

当前项目为前端本地版，不依赖后端服务，任务、课表和团队数据都保存在微信小程序本地缓存中。

## 2. 运行环境

运行前请准备：

- 微信开发者工具
- Windows、macOS 或其他可运行微信开发者工具的系统
- 一个小程序 AppID，或使用微信开发者工具提供的测试号

项目不需要执行 `npm install`，也不需要启动本地服务器。

## 3. 项目目录

主要目录说明：

```text
ddl-miniapp-revised
├─ app.js                 小程序入口
├─ app.json               页面注册、窗口和底部导航配置
├─ app.wxss               全局样式
├─ project.config.json    微信开发者工具项目配置
├─ utils/tasks.js         任务分级、日期计算、智能拆解等通用逻辑
└─ pages
   ├─ index               任务页
   ├─ schedule            手动课表页
   ├─ calendar            日历页
   ├─ stats               分析页
   └─ team                协作页
```

## 4. 导入和运行

1. 打开微信开发者工具。
2. 点击“导入项目”。
3. 项目目录选择本文件夹：`ddl-miniapp-revised`。
4. AppID 可填写自己的小程序 AppID，也可以选择测试号。
5. 点击“导入”。
6. 导入后点击顶部工具栏的“编译”。
7. 模拟器启动后，默认进入“任务”页。

如果首次运行出现缓存或编译异常，可以在微信开发者工具中选择“清缓存”，然后重新编译。

## 5. 页面功能

### 5.1 任务页

任务页是主页面，用于管理所有 DDL 任务。

可用操作：

- 点击“新建任务”创建任务。
- 填写任务名称、课程或来源、任务类型、截止日期、截止时间。
- 设置重要程度、预计耗时、当前进度。
- 勾选是否已完成。
- 勾选是否加入团队协作。
- 设置提醒时间。
- 保存后任务会出现在任务列表中。
- 点击任务卡片可以查看智能拆解和提醒节奏。
- 点击“修改任务”可重新编辑任务。
- 点击“删除任务”可删除任务。

任务分级规则：

- 根据剩余天数和重要程度计算压力分数。
- 压力较高时显示“立刻处理”或“本周重点”。
- 已完成任务会显示为低压力状态。

智能拆解规则：

- 竞赛任务会拆成主题分工、资料调研、方案设计、材料成稿、演示打磨。
- 论文任务会拆成确定题目、文献梳理、提纲搭建、初稿撰写、修改定稿。
- 考试任务会拆成整理范围、复习重点、错题回看、模拟自测。
- 普通任务会拆成理解要求、完成主体、检查提交。

### 5.2 手动课表页

从任务页点击“手动课表”进入。

可用操作：

- 点击课表空白格录入课程。
- 填写课程名称、上课地点、任课教师和备注。
- 点击“保存课程”保存。
- 点击“删除本节”清空当前格。
- 点击“示例填充”可生成示例课程。
- 点击“复制课表”可将当前课表复制到剪贴板。
- 点击“清空”可清空全部课表。

课表数据保存在本地缓存中，关闭模拟器后再次打开仍会保留。

### 5.3 日历页

日历页用于查看当前月份的 DDL 分布。

可用操作：

- 查看每天的待完成任务数量。
- 点击某一天，查看当天所有任务。
- 不同颜色表示不同负载程度：
  - 轻松：任务较少
  - 偏满：任务较多
  - 拥挤：任务集中

### 5.4 分析页

分析页用于查看任务统计和建议。

展示内容：

- 完成率
- 待办数量
- 高压任务数量
- 逾期任务数量
- 压力指数
- 长期任务拆解率
- 团队平均进度
- 任务类型分布
- 未来 7 天负载
- 本周建议

这些数据会根据本地任务列表自动计算。

### 5.5 协作页

协作页用于管理团队和共享任务。

可用操作：

- 查看当前团队成员。
- 点击“编辑成员”修改团队名称和成员名单。
- 点击“新建团队”创建新的协作团队。
- 点击“邀请”复制邀请语。
- 点击“新建协作”创建共享任务。
- 点击任务阶段卡片，可切换阶段完成状态。
- 点击“编辑”修改协作任务。
- 点击“复制摘要”复制任务进度摘要。
- 点击“移出协作”将任务从团队看板移除。
- 点击校园模板可快速创建论文、竞赛、展示、复习类协作任务。

## 6. 数据存储

当前项目使用微信小程序本地缓存：

```text
ddl_tasks_v1       任务数据
ddl_schedule_v1    课表数据
ddl_teams_v1       团队数据
ddl_active_team_v1 当前选中的团队
```

清除微信开发者工具缓存后，这些数据可能会被删除。

本地缓存版本适合演示和原型验证。如果需要多人同步、跨设备保存或正式发布，应接入云开发数据库或后端接口。

## 7. 常见问题

### 7.1 控制台出现 SharedArrayBuffer 警告

这是微信开发者工具底层环境的浏览器警告，通常不影响项目运行。

### 7.2 控制台出现 timeout

可以尝试：

1. 在微信开发者工具中清理编译缓存。
2. 重新点击“编译”。
3. 确认 `project.config.json` 中开发阶段压缩已关闭：

```json
{
  "minified": false,
  "minifyWXSS": false,
  "minifyWXML": false
}
```

4. 如果仍然超时，清除小程序本地缓存后重试。

### 7.3 页面文字显示异常

请确认文件以 UTF-8 编码保存。项目中的中文内容需要使用 UTF-8 编码读取和编辑。

### 7.4 数据不刷新

可以切换底部导航后再返回页面，页面会在 `onShow` 中重新读取本地缓存。

## 8. 开发和维护建议

### 8.1 修改页面

每个页面一般包含四个文件：

```text
页面名.js     页面逻辑
页面名.wxml   页面结构
页面名.wxss   页面样式
页面名.json   页面配置
```

修改页面时，优先保持现有结构，避免一次性大范围重构。

### 8.2 修改任务规则

任务分级和智能拆解逻辑集中在：

```text
utils/tasks.js
```

常见可改内容：

- `levelOf(task)`：修改任务压力分级规则。
- `splitPlan(task)`：修改智能拆解阶段。
- `upcomingReminders(task)`：修改提醒展示逻辑。

### 8.3 接入真实提醒

当前提醒只展示计划时间，并不会真正推送通知。如需真实提醒，需要接入微信小程序订阅消息。

### 8.4 接入云端同步

当前使用 `wx.setStorageSync` 和 `wx.getStorageSync`。如需云端同步，可将这些本地存储调用替换为云开发数据库或后端 API。

## 9. 发布前检查

正式发布前建议检查：

- 页面中文是否正常显示。
- 新建、编辑、删除任务是否正常。
- 课表保存和复制是否正常。
- 日历统计是否与任务截止日期一致。
- 分析页数据是否随任务变化更新。
- 团队任务阶段勾选是否能同步进度。
- 微信开发者工具中是否还有业务代码错误。
- 是否需要恢复代码压缩配置。

## 10. 当前限制

- 暂不支持账号登录。
- 暂不支持跨设备同步。
- 暂不支持真实消息推送。
- 暂不支持从学校教务系统自动导入课表。
- 智能拆解基于规则模板，不是实时 AI 生成。
